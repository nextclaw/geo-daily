GEO 早报 2026-08-15

📅 2026-08-15 ✍️ James Zhan 📁 Geo 📄 .md
#daily #geo

口径：Asia/Singapore；过去 24 小时窗口为 2026-08-14 09:00:53 至 2026-08-15 09:00:53。今日可核验的新信息有限，未确认到足以称为重大新增的 GEO 产品、引用机制或资本市场事件；以下保留已核验的趋势续报，历史资料均明确标注日期。

今日摘要

今日 GEO 无重大新增，附趋势延续。公开检索结果存在明显旧闻、泛首页和无关噪声，因此不把未能在官方页面核验的搜索片段写成当日事实。当前最值得关注的方向仍是：AI 搜索从一次性答案向可追问、可调用工具的代理式检索演进；GEO 衡量也应从“是否出现”扩展到“是否被引用、是否带来后续行动”。

重点动态

1. 过去 24 小时未确认新的主流 AI 搜索产品变更

  • 在 Google AI Overviews/AI Mode、ChatGPT Search、Perplexity 等重点方向，未核验到 2026-08-14 09:00 至 2026-08-15 09:00（新加坡时间）内发布的高可信重大更新。
  • 结论强度为“当前可核验范围内未发现”，不等于全球绝对没有小范围灰度或未被索引的变化。

核验入口：

  • https://blog.google/products-and-platforms/products/search/ai-mode-ai-overviews-updates/
  • https://www.perplexity.ai/hub/blog

2. Perplexity Agent API 把“搜索—工具—引用”进一步产品化（趋势续报，2026-08-13，超出本窗口）

  • Perplexity 官方称 Agent API 将网页搜索、URL 抓取、代码执行、MCP、金融与人物搜索组合为可编程检索管线，并要求 Sonar 用户在 2026-09-27 前迁移。
  • 对 GEO 的意义是：内容不仅要适合聊天答案，还要能被代理式检索稳定发现、抓取和引用；来源结构、可访问性与证据密度会成为更重要的优化对象。

来源：https://www.perplexity.ai/hub/blog/agent-api-one-place-to-build-with-llms-the-web-and-agents

3. Google 的 AI Overview→AI Mode 连续体验仍是可见度测量重点（趋势续报，2026-01-27）

  • Google 官方宣布 Gemini 3 成为 AI Overviews 的全球默认模型，并支持从 Overview 直接追问并进入 AI Mode。
  • GEO 监测不宜只记录答案是否提及品牌，还应记录链接是否突出、是否进入后续对话，以及同一问题链中的品牌保留率。

来源：https://blog.google/products-and-platforms/products/search/ai-mode-ai-overviews-updates/

4. ChatGPT Search 的核心可见度单位仍是“答案中的来源链接”（趋势续报，2024-10-31；2025-02-05 更新）

  • OpenAI 官方说明 ChatGPT Search 会根据问题决定是否联网，并在回答中提供来源链接；网站或出版商可选择是否出现在 ChatGPT Search 中。
  • 这使 GEO 的基本功仍包括：允许合规抓取、提供可核验原文、保持页面主题与实体信息一致，并持续追踪被引用而非只追踪排名。

来源：https://openai.com/index/introducing-chatgpt-search/

GEO 新兴公司融资与上市观察

过去 24 小时未发现高可信新增融资/上市动态。对 Profound、AthenaHQ、Peec AI、Otterly.AI、Scrunch AI、Goodie AI、Writesonic 及传统 SEO/搜索数据公司相关融资、并购、IPO、招股书和估值变化，本轮可核验结果没有出现可由公司公告、监管/交易所文件或高可信商业媒体确认的新事件，因此不做金额、估值或投资人判断。

可跟踪的商业化信号来自 Perplexity Agent API：其把检索、工具调用和引用能力封装成企业可购买的基础设施，并推动 Sonar 用户迁移。这是产品收入与代理式搜索基础设施竞争的观察点，但不是融资或上市事实。来源：https://www.perplexity.ai/hub/blog/agent-api-one-place-to-build-with-llms-the-web-and-agents。可信度：产品变化为官方一手来源，资本含义仅为编辑判断，不能替代财务披露。

今天值得跟进

  1. 跟踪 Perplexity Agent API 的迁移节奏、定价与企业采用，观察“AI 搜索可见度”是否从监测工具进一步变成检索基础设施的一部分。
  2. 用真实问题链测试 Google AI Overview→AI Mode 的品牌留存、引用位置和后续追问，而不是只做单轮截图。
  3. 为 ChatGPT、Google、Perplexity 分别建立“出现率—引用率—链接点击/后续行动”三层指标，避免把模型答案中的一次提及误当作商业转化。

检索质量与来源说明

  • 检索窗口：2026-08-14 09:00:53—2026-08-15 09:00:53，Asia/Singapore。
  • 实际后端：默认 web_search；随后使用 web_extract 核验官方页面。当前环境未暴露可用的 SearXNG 或 Tavily 补充搜索后端，因此没有可执行的搜索 fallback。
  • 失败与限制：默认搜索结果出现旧资料、泛首页、无关页面和疑似垃圾结果，日期过滤不稳定；同一查询未重复循环。由于没有可靠的补充搜索后端，检索在达到既定上限后收敛，不能排除尚未被索引的灰度更新。
  • 来源数量：成功提取并核验 5 个 URL，覆盖 3 个独立域名（Google、OpenAI、Perplexity）；其中 Perplexity Agent API 页面日期为 2026-08-13，Google 页面为 2026-01-27，OpenAI 页面为 2024-10-31 且有 2025-02-05 更新，均属于趋势续报而非本窗口新增。
  • 交叉验证：产品事实主要来自官方一手页面，但当日新增结论没有独立媒体或监管文件交叉验证，故“无重大新增”限定为当前可核验范围内，资本市场部分不作强结论。
