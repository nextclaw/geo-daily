GEO 早报 2026-11-28

检索窗口：Asia/Singapore 2026-11-27 09:00 至 2026-11-28 09:00。

今日摘要

过去 24 小时未检索到足够高可信、明确发生在窗口内的重大 GEO 产品、融资或上市新闻。今日重点是近期已核验的官方产品与方法论变化，作为趋势续报，不冒充当日动态。

主要动态

1. Google 将 AI 搜索引用明确为“检索—扇出—交叉验证—展示”链路

Google Search Central 的官方说明称，AI Overviews 与 AI Mode 先从 Search index 获取结果，必要时进行 query fan-out，再用 grounding 与 corroboration 支撑回答，并通过内联链接、来源卡片等形式展示来源。对 GEO 的直接含义是：单纯追求被模型提及不够，页面需要可索引、内容可靠、信息最新，并能支持具体断言。

来源：

  • https://developers.google.com/search/docs/fundamentals/gen-ai-attribution-factuality

2. Google 分开管理训练、Grounding 与 Search 生成式体验控制

Google 的新文档区分了 Search generative AI control、Google-Extended、robots 元标签和 noindex 等控制项。Search Console 的生成式 AI 控制可影响 AI Overviews/AI Mode 中的 grounding 与链接展示，但不影响模型训练，也不是普通排名信号。对品牌团队而言，GEO 已进入“可见性收益与内容使用边界并存”的治理阶段。

来源：

  • https://developers.google.com/search/docs/fundamentals/gen-ai-controls

3. Perplexity 推出 Time Machine，AI 搜索测量开始支持可复现时间切片

Perplexity 于 11 月 25 日宣布 Search API 与 Context API 的 snapshot_as_of。开发者可以限定检索只能看到某个时间点以前保存的网页，用于回放、基准测试、预测和 agent 调试。对 GEO 测量的价值在于，品牌可固定网页状态与日期，减少“页面后来更新或新闻结果泄露答案”对实验的干扰。

来源：

  • https://www.perplexity.ai/hub/blog/freeze-the-web-with-perplexity-time-machine

4. ChatGPT Search 的公开说明继续强调可抓取性与引用核验

OpenAI 说明 ChatGPT Search 会改写查询、调用搜索合作方，并可能进行后续检索；排名考虑相关性与可靠性，但不保证特定位置。希望进入 ChatGPT Search 的网站，应允许 OAI-SearchBot，并确认 CDN/主机允许其 IP 访问。OpenAI 同时提醒，搜索结果和引用可能不完整或错误，必须回到原文核验。

来源：

  • https://help.openai.com/articles/9237897-chatgpt-search

GEO 新兴公司融资与上市观察

过去 24 小时未发现高可信新增融资/上市动态。近期趋势续报显示，资本明显集中于 AI visibility 头部平台：Dealroom 9 月分析称，Profound 在 2026 年 9 月完成 1.8 亿美元 Series D、估值 18 亿美元；Sitecore 于 2026 年 6 月收购 Scrunch，交易价格未由 Sitecore 官方披露，约 2.25 亿美元为媒体报道数字。该市场更像“监测工具向企业级 AI 营销平台集中”，但上述均为历史续报，不能计入本日新增。
